# Assets do portal público

Guarde aqui os recursos visuais do site institucional: fotografias do Capítulo, imagens de eventos, fundos e ilustrações.

Sugestão de organização:

```text
assets/
├── home/       # imagens da página inicial
├── historia/   # patrono e memória do Capítulo
├── eventos/    # atividades e notícias
└── marcas/     # brasão e elementos institucionais aprovados
```

Não altere nem recrie o brasão oficial sem autorização do Capítulo.
