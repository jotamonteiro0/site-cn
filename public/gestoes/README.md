# Fotos dos Mestres Conselheiros

Adicione aqui as fotos oficiais usadas na galeria de MCs.

## Nome dos arquivos

Use sempre letras minúsculas, nomes separados por hífen e o período da gestão:

```text
nome-sobrenome.ano.semestre.jpg
```

Exemplos:

```text
joao-guilherme.2027.1.jpg
rafael-inacio.2026.2.jpg
jose-keltton.2026.1.jpg
```

Quando uma foto com o nome esperado for adicionada, ela aparecerá automaticamente na página `/gestoes` e nos destaques da página inicial. Enquanto não houver arquivo, o site mostra a insígnia institucional como placeholder.

Prefira imagens verticais, bem iluminadas, no formato JPG ou WebP.
